# Orb Collector

Open `index.html` in a browser (or serve the folder) to play.

Controls:
- Arrow keys or WASD to move.

Score is shown at the top-left and increases when you collect orbs.

Quick local server (from the workspace root):
```
python3 -m http.server 8000
# then open http://localhost:8000/game-orbs/ in your browser
```
